    MD Viewer

    A fast, accessible Markdown reader. Open a file, drop one anywhere in this window, or right-click a .md file in Explorer and choose Open with.

      Good to know

      • The section list on the left is built from the document's headings; the current section is highlighted as you scroll, and the status bar names it at the bottom. Drag its right edge to resize it, or double-click that edge to reset.
      • The ⋮ menu lists your recent files, and hovering the percentage at the bottom right shows the word count and reading time.
      • Task list checkboxes are clickable right in the reading view — no need to switch to editing first. Checking or unchecking one marks the document unsaved, the same as any other edit.
      • Editing (Ctrl+E) swaps the page for the raw Markdown and a formatting toolbar. While editing, Ctrl+B, Ctrl+I, Ctrl+K and Ctrl+` wrap the selection in bold, italic, a link or code; Tab and Shift+Tab indent and outdent; Enter carries list, task and quote markers onto the next line (press it on an empty item to end the block); pasting a link over selected text turns it into a link; inside a table Tab tidies the columns and moves to the next cell; pasting from a browser or word processor arrives as Markdown (Ctrl+Shift+V pastes plain text); dropping an image file inserts a reference to it at the caret, using a path relative to the document when the image lives under it; pasting a screenshot or copied image saves it as a new file next to the document first (a visible toast names it, since — unlike a drop — this writes something new), then inserts it the same way; Esc steps out of the text area. Toggling back to reading previews your unsaved changes without touching the file.
      • The formatting toolbar above the text area (only visible while editing) covers what the shortcuts don't: a heading button that cycles the current line through H1–H6 and back to a paragraph, strikethrough, bullet/numbered/task lists, blockquote, a fenced code block, a starter table, an image placeholder, a horizontal rule, subscript and superscript, inline and block math, a Mermaid diagram starter, a footnote (adds the reference here and the definition at the end), a definition list, an abbreviation, a highlight, inserted text, and an emoji shortcode placeholder. Each button acts on the current selection or line and announces what it did for screen readers. Arrow keys, Home and End move between toolbar buttons without leaving Tab order for the rest of the page.
      • While editing, the section list is rebuilt from what you type (click an entry to jump the caret there), and the status bar shows a live word count with the caret's line and column. Adding an item to a numbered list renumbers the rest of it, and every edit is undoable with Ctrl+Z.
      • Nothing is written to disk unless you press Ctrl+S. Saves preserve the file's original line endings and encoding, and are written to a temporary file first so a failure can't truncate your document. If another program changes the file while you have unsaved edits, the viewer keeps yours and tells you.
      • Pages are screenfuls of this window, like an e-reader — so the page count changes if you resize the window or zoom. Type a number in the page box (or press g) to jump.
      • Back returns you from any jump — a section you clicked, a link you followed, or a page you typed — not just between files.
      • The document reloads automatically when another program saves it.
      • Your preferences are stored inside MDView.exe (an NTFS file stream) — nothing is written to the registry or your user folder. If you copy the exe to a non-NTFS drive, preferences simply reset.
      • Links to websites open in your default browser. Links to other Markdown files open right here — use Alt+← to go back.
      • To make double-clicking .md files open this app: right-click a .md file → Open with → Choose another app → MDView.exe → Always.
